# 📊 Data Analytics & Python for Finance Portfolio

Welcome to my data analytics repository! This portfolio is divided into two primary tracks: **Python for Finance** (quantitative analysis, time-series, and trading strategies) and **SQL Analytics** (advanced SQL querying, data cleaning, and database management).

---

## 📂 Repository Structure

```
data-analytics-portfolio/
│
├── python_finance/          # Financial time-series analysis and trading strategies
└── sql_analytics/           # Advanced SQL queries, datasets, and relational database projects
``` 

## 📈 1. Python for Finance (`python_finance/`)

This module covers the journey from core data manipulation with Pandas to backtesting and evaluating quantitative trading strategies.

| # | Notebook / File | Focus & Key Concepts |
| :--- | :--- | :--- |
| **01** | **The Pandas Library** | Core DataFrame operations, data cleaning, indexing, and structural manipulation. |
| **02** | **Matplotlib & Seaborn** | Visualizing price action, volume histograms, and customizing charts. |
| **03** | **Master Fin Analysis with Pandas** | Computing percentage returns, rolling statistical windows, and financial aggregations. |
| **04** | **Time Factor in Finance** | Handling financial timestamps, datetime indexes, timezones, and resampling time-series data. |
| **05** | **Trading Strategy with Pandas** | Implementing quantitative rules, technical indicator logic, and generating trade signal columns. |
| **06** | **Analyse a Trading Strategy with Pandas** | Evaluating backtest performance, cumulative returns, drawdowns, and strategy metrics. |
